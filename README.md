# Dictado para niñ@s

Aplicación web inclusiva para practicar dictado en **català**, **español (España)** e **inglés**.

## Funciones

- Dictado palabra por palabra con resaltado visual.
- Repetición de una palabra pulsando sobre ella.
- Continuación desde la palabra seleccionada.
- Pausas configurables entre palabras.
- Nombrado opcional de signos de puntuación.
- Pausa al encontrar signos o pausa larga automática.
- Guardado automático del texto y la configuración en el navegador.
- PWA instalable en móvil y ordenador.

## Publicación

El proyecto está preparado para GitHub Pages. Activa Pages desde `Settings → Pages`, seleccionando la rama `main` y la carpeta raíz.

## Uso

Abre `index.html` en Chrome, Edge o Safari. Pulsa **Empezar** para iniciar la voz; después puedes pulsar cualquier palabra para repetirla y **Continuar** para seguir desde ese punto.
